=== Conteo de elementos por categoría

`updateCountLabel` calcula los totales y arma el texto con el formato pedido. `countElements` recorre el diagrama de forma recursiva: cuando encuentra un paquete, lo cuenta y entra a contar los elementos que contiene. Las relaciones (asociaciones, dependencias, etc.) no son elementos y no se cuentan.

#archivo("AppFrame.java — métodos nuevos")[
```java
/**
 * Cuenta los elementos del diagrama y actualiza la barra de estado.
 * @param editor el editor cuyo diagrama se cuenta
 */
private void updateCountLabel(DiagramEditor editor) {
  int[] counts = new int[4]; // 0 Package, 1 Class, 2 Component, 3 Note
  countElements(editor.getDiagram().getChildren(), counts);
  int total = counts[0] + counts[1] + counts[2] + counts[3];
  countLabel.setText(String.format(
    "Total Items: %02d | Package: %02d | Class: %02d | Component: %02d"
    + " | Note: %02d", total, counts[0], counts[1], counts[2], counts[3]));
}

/**
 * Recorre los elementos, incluidos los que están dentro de un paquete.
 * Las relaciones no se cuentan.
 */
private void countElements(Collection<DiagramElement> elements,
  int[] counts) {
  for (DiagramElement element : elements) {
    if (element instanceof PackageElement) {
      counts[0]++;
      countElements(((PackageElement) element).getChildren(), counts);
    } else if (element instanceof ClassElement) {
      counts[1]++;
    } else if (element instanceof ComponentElement) {
      counts[2]++;
    } else if (element instanceof NoteElement) {
      counts[3]++;
    }
  }
}
```

```java
private void updateSelectionLabel() {
  List<DiagramElement> selected = getCurrentEditor().getSelectedElements();
  // al hacer clic en una zona vacia el editor selecciona el propio diagrama
  if (selected.isEmpty() || selected.get(0) instanceof StructureDiagram) {
    selectionLabel.setText(" Sin selecci\u00f3n");
  } else if (selected.size() > 1) {
    selectionLabel.setText(" Varios elementos seleccionados");
  } else {
    DiagramElement element = selected.get(0);
    selectionLabel.setText(" Category: " + getCategory(element)
      + " | Name: " + getElementName(element));
  }
}
```

=== Categoría: `getCategory()`

Devuelve `Package`, `Class`, `Component` o `Note` según el tipo del elemento. Las relaciones (asociación, dependencia, herencia, etc.) implementan `Connection` y se muestran como `Relation`. Cualquier otro objeto devuelve `Unknown`, para que la barra nunca quede vacía.

#archivo("AppFrame.java — getCategory()")[
```java
private String getCategory(DiagramElement element) {
  if (element instanceof PackageElement) return "Package";
  if (element instanceof ClassElement) return "Class";
  if (element instanceof ComponentElement) return "Component";
  if (element instanceof NoteElement) return "Note";
  if (element instanceof Connection) return "Relation";
  return "Unknown";
}
```
]

=== Nombre: `getElementName()`

Los elementos con texto (paquete, clase, componente y nota) implementan `LabelSource`, y de ahí se obtiene el nombre. Se cuidan los casos límite: si el texto es nulo o está vacío se muestra `(sin nombre)`, los saltos de línea se reemplazan por espacios para que el nombre quepa en una sola línea, y los nombres de más de 30 caracteres se acortan con `...`. Los elementos sin `LabelSource`, como las relaciones, muestran `-`.

#archivo("AppFrame.java — getElementName()")[
```java
private String getElementName(DiagramElement element) {
  if (!(element instanceof LabelSource)) {
    return "-";
  }
  String text = ((LabelSource) element).getLabelText();
  if (text == null) {
    return "(sin nombre)";
  }
  text = text.replace('\n', ' ').trim();
  if (text.length() == 0) {
    return "(sin nombre)";
  }
  if (text.length() > 30) {
    text = text.substring(0, 30) + "...";
  }
  return text;
}
```
]

=== Cuándo se actualiza

`AppFrame` ya implementaba `SelectionListener` (patrón Observer ya presente en TinyUML): el editor avisa con `selectionStateChanged()` cada vez que cambia la selección. Basta con llamar a `updateSelectionLabel()` al final de ese método.

Al borrar un elemento seleccionado hace falta un paso más. El editor avisa a sus listeners con `elementRemoved` y recién después reinicia su selección. Si la etiqueta se actualizara directamente ahí, todavía mostraría el elemento borrado. Por eso la llamada se aplaza con `SwingUtilities.invokeLater`, que la ejecuta cuando la selección ya está vacía. Como deshacer una creación también dispara `elementRemoved`, Undo queda cubierto.

#archivo("AppFrame.java — selectionStateChanged()")[
```java
public void selectionStateChanged() {
  boolean hasSelection = getCurrentEditor().getSelectedElements().size() > 0;

  menumanager.enableMenuItem("CUT", hasSelection);
  menumanager.enableMenuItem("COPY", hasSelection);
  menumanager.enableMenuItem("DELETE", hasSelection);

  toolbarmanager.enableButton("CUT", hasSelection);
  toolbarmanager.enableButton("COPY", hasSelection);
  toolbarmanager.enableButton("DELETE", hasSelection);
  updateSelectionLabel();
}
```
]

```java
public void elementRemoved(DiagramEditor editor) {

}
```
